# AGENTS.md — Workspace

pnpm workspace monorepo for VS Code extensions. This file covers the **workspace**; each extension carries its own `AGENTS.md` with the detail.

- Extensions live in `extensions/*`; shared packages (if any) in `packages/*`.
- Package manager: **pnpm**.
- To work on a specific extension, read that extension's own `AGENTS.md` and `CLAUDE.md` — e.g. `extensions/reset-sizes/AGENTS.md` and `extensions/reset-sizes/CLAUDE.md` — and its `docs/`.
